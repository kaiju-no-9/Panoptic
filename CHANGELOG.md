# Changelog

## 0.1.2

- Add an alt-text quick fix, local link navigation and references, and heading symbols for document and workspace search.
- Include reference-style Markdown links in link analysis and navigation.

## 0.1.1

- Use currently supported GitHub macOS runners for Apple Silicon and Intel release builds.

## 0.1.0

- Zed extension attaching `panoptic-lsp` to the built-in Markdown language.
- Diagnostics: missing image alt text, broken local links/images, broken heading anchors.
- Completion for relative file links and heading anchors.
- Hover for local links, fragment-only links and remote URLs (text only).
- Markdown snippets: `h1`, `h2`, `link`, `image`, `task`, `quote`, `code`, `table`.
